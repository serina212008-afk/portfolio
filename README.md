Web Development Task 2 – Personal Portfolio Website Objective

The goal of this task is to create a personal portfolio website to showcase skills, projects, and achievements. This helps in developing proficiency in HTML, CSS, responsive design, and UI/UX principles.

Tools Used

HTML5 – Structure and layout

CSS3 – Styling, typography, and responsive design

JavaScript (optional) – For interactivity

VS Code / any code editor – Development environment

Browser – Testing and preview (Chrome/Edge/Firefox)

Steps Performed

Created a project folder with separate HTML, CSS, and JS files.

Designed a navigation bar with links to different sections.

Added a hero section with personal introduction and image.

Created sections for About Me, Skills, Projects, and Contact Information.

Styled the portfolio using CSS colors, fonts, and spacing for a professional look.

Made the website responsive using media queries so it looks good on all devices.

Tested the portfolio on multiple browsers for compatibility and responsiveness.

Outcome

A fully functional, responsive, and professional portfolio website.

Website effectively showcases personal skills, projects, and achievements.

Demonstrates practical web development and UI/UX design skills
